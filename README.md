# Habitos-tfc

## Descripción
Hábitos permite a los usuarios crear hábitos personalizados, registrar su cumplimiento diario y visualizar su evolución mediante rachas, porcentajes de cumplimiento y gráficas, con el objetivo de fomentar la constancia.

## Objetivos
- Diseñar una base de datos relacional para usuarios, hábitos y registros.
- Desarrollar una API REST con la lógica de negocio.
- Implementar una app cliente (móvil/web) intuitiva.
- Sistema de autenticación de usuarios.
- Notificaciones/recordatorios diarios.
- Estadísticas visuales de progreso.
- Gamificación (logros, rachas, niveles).

## Tecnologías
- Backend: Spring Boot
- Base de datos: PostrgreSQL
- Frontend: Flutter/Angular
- Autenticacion: JWT
- Control de versiones: Git + GitHub

## Estructura
- backend/: API REST 
- frontend/: Aplicacion cliente 
- docs/: Memoria, diagramas y planificación
